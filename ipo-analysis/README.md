# IPO Analysis Desk

A public section of the fund website at `/ipo-analysis/`. It lists every DRHP / RHP analysed, each with its due-diligence note
and three downloadable, formula-driven Excel models, plus blank templates.

| Path | What |
|---|---|
| `index.html`, `view.html`, `assets/` | The website. Static; it reads `data/*.json` and `companies/*/` live |
| `data/index.json` | One row per analysed issuer, generated by `toolkit/build_issuer.py` |
| `data/queue.json`, `data/seen.json` | Filings waiting for analysis / already processed |
| `data/sources.json` | Where the routine looks for new filings, and how many it analyses per run |
| `companies/<slug>/` | `facts.json` (figures + cites), `meta.json` (call, headline, flags), `note.md`, generated `.xlsx` |
| `templates/` | Blank templates with illustrative numbers |
| `toolkit/` | Workbook builders, `build_issuer.py`, `verify.py` (independent recalculation; must pass) |
| `ROUTINE.md` | Standing instructions the scheduled Claude routine follows on every run. Edit it on GitHub to change behaviour |

Commands the routine runs (you never need to run these yourself):

```bash
pip install -r ipo-analysis/toolkit/requirements.txt
python3 ipo-analysis/toolkit/build_issuer.py <slug>   # build one issuer + refresh index
python3 ipo-analysis/toolkit/verify.py                # verification gate
python3 ipo-analysis/toolkit/build_templates.py       # rebuild blank templates
```

The pages carry `noindex` until compliance signs off. Every page shows
`[FIRM-APPROVED SEBI DISCLAIMER AND DISCLOSURE BLOCK TO BE INSERTED]` until the firm supplies the wording.
